# Security Policy

## Supported Versions

LocalAgents is currently in early alpha (`0.x`). Only the latest released version receives
security fixes until a `1.0` stability policy is established.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately using
[GitHub Security Advisories](https://github.com/harshbhalodia/localagents/security/advisories/new)
for this repository. This lets us discuss and fix the issue before it's publicly disclosed.

Please include:

* A description of the vulnerability and its potential impact
* Steps to reproduce it (a minimal repro script is ideal)
* The version(s) of `localagents` and `strands-agents` affected

We'll acknowledge reports as soon as possible and keep you updated as we investigate and fix
the issue.
